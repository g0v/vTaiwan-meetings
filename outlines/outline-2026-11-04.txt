### 2. Thompson Lin（書籍與公共參與概念分享）  

| 概念 | 內容說明 |
|------|----------|
| **《共議未來》**（CIDS 書） | - 以「人本」為核心，探討公共參與的三大能力：**知識中介者、信任搭建者、政策促進者**。 |
| **1. 知識中介者** | - 辨識領域內現有知識與限制（例：台灣地熱能源的法規、技術成熟度）。- 將專業知識翻譯成非專業人士易懂的語言，促進跨領域共識。 |
| **2. 信任搭建者** | - **共感**：建立讓參與者願意分享個人經驗的安全環境。- **反思**：引導不同立場思考彼此行為背後的原因。- **互動**：促使不同價值觀互相碰撞，形成微共識。- 案例：2020 台北雙年展「非核家園」劇場，透過角色扮演讓公部門、民眾、學者等多方了解彼此立場。 |
| **3. 政策促進者** | - 具備「政策創業」精神，將公共對話成果具體化為政策建議。- 透過多元參與機制（協商劇場、情境模擬、換位思考等）擴大社會聲音，連結資源，推动政策改革。 |
| **實務工具與概念** | - **利害關係人象限**：將關係人分為四象限，提供分層溝通策略（*蛋黃區*：核心決策者；*蛋白區*：大眾）。- **提綱設計**：須簡潔且具想像力，例：「未來十年，我們想要的城市樣貌是什麼？」能激發民眾思考與回應。 |
| **附錄** | - 書中收錄全球數千個公民參與案例（包含 vTaiwan 用例）。- 強調「分層溝通」：對核心決策者採取結盟模式，對大眾則以資訊流通與興趣激發為主。 |

### 3. Bestian（工具與方法建議）
